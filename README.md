# 台湾華語 ワンタップ 🇹🇼

台湾のご家族と その場で話すための、ワンタップ会話＆ことば組み立てアプリです。

- **ひとこと**: 相槌・挨拶・気遣い・食事・移動・車内・景色のフレーズをタップすると、繁體字（台湾華語）を大きく表示。ピンイン・カタカナ・日本語訳つき、🔊で読み上げ。
- **ことばで文**: 「今日」「天気」「よい」のように単語を並べて「OK！」を押すと、台湾華語の自然な文（例: 今天天氣很好！）を組み立てます。
- 単一HTML（外部CDN・ビルド不要）。スマホ縦画面に最適化、ホーム画面に追加できます。
